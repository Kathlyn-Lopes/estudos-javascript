## 📌 Sobre o repositório

Este repositório foi criado para documentar minha evolução nos estudos de **JavaScript**, reunindo exercícios, exemplos e pequenos projetos desenvolvidos durante o processo de aprendizagem.

O objetivo é construir uma base sólida em **lógica de programação**, compreender os principais conceitos da linguagem e desenvolver gradualmente a capacidade de criar scripts para manipulação de dados, integração entre sistemas e automação de tarefas.

Os conteúdos serão adicionados conforme o avanço dos estudos, permitindo acompanhar minha evolução desde os fundamentos da linguagem até aplicações práticas relacionadas a processos, APIs e automações.

Este repositório representa uma jornada de aprendizado contínuo. Os exemplos e projetos aqui documentados serão desenvolvidos e atualizados conforme os conhecimentos forem adquiridos na prática.

---

## 🎯 Objetivos de Aprendizagem

- Compreender os fundamentos da linguagem JavaScript.
- Desenvolver lógica de programação por meio de exercícios práticos.
- Aprender a trabalhar com variáveis, tipos de dados e operadores.
- Utilizar estruturas condicionais e estruturas de repetição.
- Criar e utilizar funções para organizar e reutilizar código.
- Trabalhar com arrays e objetos para organização e manipulação de dados.
- Aprender métodos utilizados para tratamento e transformação de dados.
- Compreender conceitos básicos de JSON.
- Evoluir gradualmente para o consumo e manipulação de dados por meio de APIs.
- Desenvolver scripts simples para automatização de tarefas.
- Aplicar futuramente JavaScript em integrações e workflows de automação.
- Documentar exercícios e aprendizados utilizando Git e GitHub.

## 🚀 Contexto

Em operações de Suporte Técnico e Service Desk, diversas atividades envolvem tratamento de informações, integração entre sistemas, análise de dados e execução de tarefas repetitivas que podem ser otimizadas por meio de automações.

O estudo de JavaScript faz parte da minha evolução técnica, com o objetivo de desenvolver conhecimentos de programação que possam futuramente ser aplicados na criação de scripts, manipulação de dados, consumo de APIs e integração entre diferentes ferramentas.

A linguagem também complementa meus estudos em automação com n8n, permitindo compreender melhor a lógica utilizada em workflows, tratamento de dados em JSON e personalização de processos automatizados.

Ao longo dos estudos, pretendo relacionar os conceitos aprendidos a cenários próximos da minha experiência profissional, como organização de dados de chamados, análise de indicadores, tratamento de informações de sistemas ERP e automação de processos de Service Desk.

Este repositório será atualizado conforme minha evolução prática, mantendo separados os conteúdos estudados, exercícios realizados e projetos desenvolvidos.
